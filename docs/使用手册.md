## 一、快速上手

### 1.1 环境要求

- **PC**: Windows / macOS / Linux，USB 接口充足
- **手机**: Android 11+ 真机，每台登录 1 个微信号
- **SIM 卡**: 每台手机 1 张独立 4G SIM 卡
- **软件**: Python 3.10+、ADB、微信最新版

### 1.2 本地环境搭建

```bash
# 1. 进入项目目录
cd wechat_farm

# 2. 创建虚拟环境并安装依赖
python -m venv wechat_env
wechat_env\Scripts\activate         # Windows
# source wechat_env/bin/activate    # macOS / Linux
pip install -r requirements.txt

# 3. 手机端配置
#    a) 开启开发者模式 → USB 调试 → 不锁定屏幕
#    b) USB 连接电脑，手机上点「允许 USB 调试」
#    c) 安装 uiautomator2 agent：
python -m uiautomator2 init
```

### 1.3 验证连通性

```bash
adb devices                          # 看到设备序列号即正常
python -m weditor                    # 浏览器打开 http://localhost:17310
```

### 1.4 初始化并录入账号

```bash
# 初始化数据库
python main.py init

# 录入账号
python -c "
from storage.db import Database
db = Database('wechat_farm.db')
db.insert_account(
    id='acc_001',
    wechat_id='wxid_xxx',            # 微信号
    device_serial='ABCD1234',        # adb devices 看到的序列号
    registration_date='2026-07-01',  # 注册日期
    batch_name='batch_a',
    persona_id='p01',
)
db.bind_device(serial='ABCD1234', account_id='acc_001', model='Moto G54')
"
```

或直接用 SQLite：

```bash
sqlite3 wechat_farm.db
INSERT INTO accounts (id, wechat_id, device_serial, registration_date, batch_name, persona_id)
VALUES ('acc_001', 'wxid_xxx', 'ABCD1234', '2026-07-01', 'batch_a', 'p01');
```

### 1.5 录入好友

```python
db.add_friend(account_id='acc_001', friend_name='张三')
```

剧本中的聊天动作会从此表随机抽取联系人。不支持自动加好友（红线行为），需手动录入。

### 1.6 功能验证

```bash
# 一键跑通全部核心功能（约20分钟）
#   ① 发朋友圈(1张图)  ② 朋友圈点赞+评论  ③ 发送文字
#   ④ 发送图片        ⑤ 刷视频号(3min)    ⑥ 阅读公众号(2min)
#   ⑦ 浏览收藏夹(1min)
# 联系人配置: 编辑 scripts/fast_test.py 顶部 CONTACT_NAME
python main.py fast-debug
```

### 1.7 部署到服务器

服务器上有其他设备时，改用安全方式初始化（不干扰其他设备）：

```bash
# 1. 手动建库
python -c "from storage.db import Database; db = Database('wechat_farm.db'); db.init_db()"

# 2. 录入账号（同1.4）

# 3. 验证（只操作指定设备）
python -c "
import uiautomator2 as u2
d = u2.connect('ABCD1234')          # 指定序列号，不影响其他设备
d.app_start('com.tencent.mm')
print('OK')
"
```

### 1.8 设置定时任务

**Linux（Cron）：**

```bash
crontab -e
```

添加：

```
0 7 * * * cd ~/wechat_farm && ./wechat_env/bin/python main.py run >> logs/cron.log 2>&1
0 8 * * 1 cd ~/wechat_farm && ./wechat_env/bin/python main.py advance >> logs/cron.log 2>&1
```

**Windows（任务计划程序）：**

```powershell
schtasks /create /tn "WechatFarm_Daily" /tr "d:\养微信号\wechat_farm\wechat_env\Scripts\python.exe d:\养微信号\wechat_farm\main.py run" /sc daily /st 07:00
schtasks /create /tn "WechatFarm_Advance" /tr "d:\养微信号\wechat_farm\wechat_env\Scripts\python.exe d:\养微信号\wechat_farm\main.py advance" /sc weekly /d MON /st 08:00
```

### 1.9 启动 Agent 监控

对 AI Agent（如 Claude Code）发送以下指令：

```
请阅读 wechat_farm/CLAUDE.md，你现在是本项目的上层调度员，24h 辅助项目运行。
设置每天早上 7:05 检查昨晚日志，有失败动作通知我
设置每天晚上 22:00 生成今日报告总结
设置每 4 小时检查 adb devices，设备离线通知我
```

## 二、增加手机和微信号

### 2.1 新增一台手机

```
新手机配置清单:
  □ 开启开发者模式 → USB 调试 → 不锁定屏幕
  □ 插入独立 4G SIM 卡
  □ 安装 uiautomator2 agent: python -m uiautomator2 init
  □ USB 连接服务器，确认 adb devices 能识别
```

### 2.2 录入新账号

```python
from storage.db import Database
db = Database('wechat_farm.db')

# 插入新账号（用新的 id 和序列号）
db.insert_account(
    id='acc_002',                     # ← 新的账号 ID
    wechat_id='wxid_yyy',             # ← 新的微信号
    device_serial='EFGH5678',         # ← 新手机的序列号
    registration_date='2026-07-15',   # ← 新的注册日期
    batch_name='batch_a',
    persona_id='p02',                 # ← 用不同人格，避免同质化
)
db.bind_device(serial='EFGH5678', account_id='acc_002', model='Moto G54')
```

### 2.3 录入新账号的好友

```python
db.add_friend(account_id='acc_002', friend_name='李四')
```

### 2.4 验证新设备

```bash
python -c "
import uiautomator2 as u2
from core.wechat_control import WeChatControl
from core.humanizer import Humanizer
d = u2.connect('EFGH5678')  # 指定新手机的序列号
wc = WeChatControl(d, Humanizer(), account_id='acc_002')
wc.open_moments()
wc.scroll_moments(3)
print('OK')
"
```

### 2.5 生效

Cron 已配置 `main.py run`，会自动遍历数据库中所有活跃账号。新账号录入后**无需修改任何配置**，第二天自动加入执行。

### 2.6 移除账号

```sql
-- 暂停（保留数据）
UPDATE accounts SET mode='paused' WHERE id='acc_002';

-- 彻底删除
DELETE FROM accounts WHERE id='acc_002';
DELETE FROM device_bindings WHERE account_id='acc_002';
```

## 三、更换服务器

### 3.1 备份原有数据

```bash
# 在原服务器上
cd ~/wechat_farm
tar -czf wechat_farm_backup.tar.gz \
    wechat_farm.db \
    logs/ \
    config/
scp wechat_farm_backup.tar.gz user@新服务器IP:~/
```

### 3.2 新服务器搭建

```bash
# 1. 安装系统依赖
sudo apt install python3-venv python3-pip adb -y

# 2. 克隆项目（或从 GitHub 拉取）
git clone git@github.com:raregas-48/Wechat_farm.git ~/wechat_farm
cd ~/wechat_farm

# 3. 创建虚拟环境并安装依赖
python3 -m venv wechat_env
source wechat_env/bin/activate
pip install -r requirements.txt

# 4. 恢复数据库
tar -xzf ~/wechat_farm_backup.tar.gz
```

### 3.3 重新绑定设备

如果新服务器上手机的 USB 路径变了（或换了手机），更新绑定：

```sql
UPDATE accounts SET device_serial='新序列号' WHERE id='acc_001';
UPDATE device_bindings SET serial='新序列号' WHERE account_id='acc_001';
```

### 3.4 验证并恢复定时任务

```bash
# 验证功能
python -c "
import uiautomator2 as u2
d = u2.connect('新序列号')
d.app_start('com.tencent.mm')
print('OK')
"

# 重新设置 Cron（同 1.8）
crontab -e
```

### 3.5 多台手机批量迁移

如果是批量迁移账号（设备不变），只需：

1. 克隆代码 → 装依赖
2. 拷贝 `wechat_farm.db` → 恢复 Cron
3. 所有手机 USB 插到新服务器 → `adb devices` 确认

## 四、日常运维

### 4.1 每日检查

```bash
# 查看今日执行情况
sqlite3 wechat_farm.db "SELECT action_type, COUNT(*), SUM(CASE WHEN success THEN 1 ELSE 0) FROM action_logs WHERE date(executed_at)=date('now') GROUP BY action_type;"

# 查看失败动作
sqlite3 wechat_farm.db "SELECT account_id, action_type, error_msg FROM action_logs WHERE date(executed_at)=date('now') AND success=0;"

# 查看设备在线状态
adb devices

# 查看日志
tail -50 logs/wechat_farm_$(date +%Y-%m-%d).log
```

### 4.2 每周操作

```bash
python main.py advance    # 推进账号阶段（Cron 已自动执行）
python main.py report     # 生成周报
```

### 4.3 健康检查

系统内置 18 项健康检查，帮助快速定位问题。

**设备层检查（12 项）— 无需账号：**

```bash
python -c "
from monitor.health_check import DeviceHealthChecker
result = DeviceHealthChecker().run_all()
for k, v in result.items():
    status = 'OK' if v else 'FAIL'
    print(f'  [{status}] {k}')
"
```

检查项：ADB 连接、ATX Agent、设备信息、微信已安装、冷启动、前台、4 个 Tab 切换、截图、朋友圈页面、搜索页面、视频号页面、存储写入。

**账号层检查（6 项）— 需指定设备：**

```bash
python -c "
import uiautomator2 as u2
from monitor.health_check import AccountHealthChecker
d = u2.connect('N0URB40116')
result = AccountHealthChecker(d).run_all()
for k, v in result.items():
    status = 'OK' if v else 'WARN'
    print(f'  [{status}] {k}: {v}')
"
```

检查项：微信首页、朋友圈可见性（OCR 检测限制关键词）、搜索功能、发消息功能、验证码检测、功能限制检测。

**或用 CLI 命令（需数据库中已录入账号）：**

```bash
python main.py health-check acc_001
```

**常见排查流程：**

```
动作失败 → 跑设备层 12 项 → 全部 OK？
  ├─ 否 → 修复 ADB/USB/微信启动问题
  └─ 是 → 跑账号层 6 项 → 全部 OK？
       ├─ 否 → 根据结果处理（降级/暂停/人工介入）
       └─ 是 → 跑 fast-debug 验证 → 仍失败？检查微信版本
```

### 4.4 账号异常处理

| 症状 | 处理 |
|------|------|
| 连续 3 天同一动作失败 | 检查微信是否更新，重新跑 weditor 确认定位 |
| 消息延迟 > 5s | `UPDATE accounts SET mode='consume_only' WHERE id='acc_xxx'` |
| 频繁滑块验证 | `UPDATE accounts SET state='cooldown' WHERE id='acc_xxx'` |
| 设备掉线 | 重新插拔 USB，运行 `adb devices` 确认 |

### 4.5 日志清理

```bash
# 删除 30 天前的日志
find logs/ -name "*.log" -mtime +30 -delete
```

## 五、如何修改剧本

各阶段剧本位于 `scripts/` 目录下：

| 文件 | 阶段 |
|------|------|
| `trust_building.py` | 信任积累期（第 1-2 周） |
| `light_interact.py` | 轻度互动期（第 3-4 周） |
| `normal_use.py` | 正常使用期（第 2-3 月） |
| `mature.py` | 成熟期（3 个月后） |

### 5.1 剧本结构

每条 `Action` 包含 4 个可调参数：

```python
Action(动作类型, "开始时间", "结束时间", (最短秒数, 最长秒数), params={...})
```

### 5.2 调整时间窗口

```python
# 改前: 早上 8:00-9:00 刷朋友圈 5-10 分钟
Action(ActionType.SCROLL_MOMENTS, "08:00", "09:00", (300, 600))

# 改后: 早上 9:00-10:00 刷朋友圈 10-15 分钟
Action(ActionType.SCROLL_MOMENTS, "09:00", "10:00", (600, 900))
```

### 5.3 调整操作频率和概率

```python
# 点赞次数范围
params={"count": (1, 2)}          # 每次 1-2 条 → 改成 (3, 5) 增加频次

# 视频号点赞概率
params={"like_rate": 0.2}         # 20% 概率 → 改成 0.5 提高频率

# 聊天联系人数
params={"contact_count": (1, 2)}  # 1-2 人 → 改成 (3, 5) 增加社交
```

### 5.4 添加新动作

```python
# 例如在 trust_building 中增加一次下午的收藏夹浏览：
Action(ActionType.BROWSE_FAVORITES, "14:00", "15:00", (120, 300)),
```

### 5.5 移除或暂停动作

```python
# 方式 1: 注释掉该行（推荐，可恢复）
# Action(ActionType.MAKE_PAYMENT, "16:30", "18:00", (60, 300)),

# 方式 2: 删除该行（不可恢复）
```

### 5.6 修改后生效

剧本修改后无需重启，下次 Cron 执行时自动使用新版本。修改后建议先 `fast-debug` 验证一次。

### 5.7 根据日志调整（Agent 协助）

```
日志发现: LIKE_MOMENT 成功率下降
  ↓
Agent 建议: 将 count 从 (2,3) 降为 (1,1)，观察 3 天
  ↓
你确认后 Agent 直接修改文件并提交
  ↓
3 天后日志显示成功率恢复 → 保持新参数
```

## 六、常见问题

| 问题 | 解决 |
|------|------|
| `ModuleNotFoundError: No module named 'uiautomator2'` | 未激活虚拟环境，用 `wechat_env/bin/python` |
| 手机锁屏后自动化卡住 | 去开发者选项开启「不锁定屏幕」；代码已有息屏唤醒 |
| `adb devices` 显示 offline | 重插 USB，换数据线，检查 Hub 供电 |
| EasyOCR 首次运行慢 | 下载模型 ~100MB，仅首次 |
| 微信更新后定位失效 | 用 `python -m weditor` 重新抓取，更新 `config/wechat_elements.py` |
| 换了字体后 OCR 找不到联系人 | 字体改动会影响 OCR 识别率，建议用系统默认字体 |
| 多台手机 `adb devices` 时有时无 | 每台独立 USB 口，减少 Hub 串联层级 |
| `main.py run` 会影响其他设备吗 | 不会，只操作数据库中已录入的设备 |
| 如何只操作一台设备 | `u2.connect('序列号')` 指定，不调用 `discover_all` |
| 如何更换联系人 | 编辑 `scripts/fast_test.py` 顶部 `CONTACT_NAME` |
